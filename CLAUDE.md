# Size Calculator (index.html)

Single-file trade position sizing tool. No build step, no dependencies, no framework — one self-contained HTML file with vanilla JS. Keep it that way.

## What it does
Sizes shares and options positions off a dollar risk amount (account size × risk %), using Tradier's REST API directly from the browser (key stored in localStorage, never in the file). Account size and risk % persist in localStorage. Risk $ is styled as the loud number (big, bold, red — it's the max loss). Risk % preset chips: .125/.25/.50/1/2/3%, plus fixed dollar chips (default 100/250/500/1000, editable via the ✎ chip → comma list, deduped, max 6, persisted as risk_usd_presets). Active chips track whatever the current values resolve to — a $ tap can light its matching % chip too. The Account & Risk card is OPEN by default; a manual collapse is remembered (risk_open). The collapsed title shows live risk $ · % (updateRiskStatus).

## Architecture
- **Tradier API**: `api.tradier.com/v1` (or sandbox), Bearer auth. Endpoints used: `/markets/quotes` (greeks=true), `/markets/options/expirations`, `/markets/options/chains`, `/markets/timesales` (5min interval, for the chart)
- **Cross-device sync** (optional, off by default): passphrase-only, no accounts. WebCrypto derives sync_id (SHA-256, which KV mailbox) and sync_key (PBKDF2 200k → AES-GCM-256) — the passphrase itself is never stored or sent; the blob (buildBackup, BACKUP_KEYS = sync payload) is encrypted on-device before PUT to the tiny Cloudflare Worker in `worker/` (SYNC_SERVER is hardcoded to https://size-calc-sync.aolfat.workers.dev for now; the worker source stays in `worker/`). Every value-changing store.set on a BACKUP_KEY marks syncDirty (persisted as sync_dirty; no-op rewrites don't count) and debounce-pushes 2.5s; pushes are pull-merge-push with compare-and-swap (`PUT ?ift=<t read>` → 409 + current record if another device wrote in between; client merges and retries) so a push can never clobber an unseen change even in a same-second race — dirty keys win locally, clean keys adopt remote, saved_positions merge per id with deleted_positions tombstones (removeSaved writes one, pruned after 180d) so deletes propagate instead of resurrecting; the per-push dirty snapshot is restored on failure so mid-flight edits survive. An unreadable cloud blob never wedges sync: pulls report it and pushes replace it. Both sync_id and sync_key come out of the one slow PBKDF2 (512 bits split), so the public id is no cheaper to brute-force than the key. Pulls on load, focus, visibilitychange, and a 60s visible poll (`?meta=1` timestamp check first, blob only when newer; the poll also retries a failed push). last_sync_t gates re-apply; syncSuppress stops remote applies re-marking dirty; syncRehydrate re-reads storage into the UI without a reload (keeps the loaded ticker input). Enabling adopts the cloud copy when one exists (positions still merge), else seeds it. Wrong passphrase = different id = 404, reads as empty. sync_id/sync_key/sync_dirty/last_sync_t are device-local, never in the payload (sync_url no longer read — orphan key on older devices). Worker: GET/PUT one `{t, blob}` record per id in KV, 200KB cap, 400d TTL refreshed on write, sees ciphertext only
- **Stops**: ONE global stop pair in the ticker card, used everywhere. Long stop (shares-long + calls, blank = LOD) and short stop (shares-short + puts, blank = HOD). Only the stop matching tradeCtx() is shown/drawn (shares follow the Long/Short toggle, options follow chain side; Both view shows both). Chart click sets the context's stop; in Both view, below price = long, above = short. Quick lookup uses the pair when its ticker matches the loaded quote, else that underlying's LOD/HOD. Inputs clear on symbol change
- **Shares mode** (default): Shares = risk$ / |entry − stop|. The Long/Short toggle lives FIRST in the Entry & stops row (direction is the first decision; dirField hidden in options mode where chain side plays that role)
- **Options mode**: straddle T-chart — calls left, strike center column, puts right, mirrored columns (Cts, Loss/ct, OI, Vol, Δ, Mid | Strike | reversed). Single-side views (Calls/Puts) use a wider layout with bid/ask/IV/@stop/total. Mobile (<500px) shows OI/Vol/Δ/Mid per side (m-size hides Loss/Cts/Total — sizing lives in the tap-in detail; m-oi and m-delta re-shown) and compacts number formats; colspans both 9 / single 5 / banner 4. Chain header is locked while scrolling: sticky thead — on desktop the chain is its own scroll panel (.chain-scroll, max-height ~100vh); on mobile (table fits, no scroll wrapper) it sticks to the page below the context bar (--sbh offset)
- **Share cards**: 'share' buttons on the shares sizing card, pinned cards, and saved positions render a hand-drawn canvas PNG (drawShareCard — deliberately NOT a DOM screenshot: no deps, Safari foreignObject is unreliable) and copy it via ClipboardItem (promise constructed inside the gesture for Safari); falls back to downloading the PNG
- **Simulate returns**: Black-Scholes (normCdf via Abramowitz-Stegun, RISK_FREE 4%) canvas modal — return % over time (now → expiry) at a slider-chosen underlying price, IV held constant. Green above breakeven / red below via canvas clipping, max-loss floor, drag crosshair readout (est $/ct, %, $ P&L × qty). Price chips: stop / now / 1R / 2R (R = distance to stop, side-aware). Entry points: chain detail row (simReg by OCC symbol), pinned cards (entry = mid), saved cards (entry = YOUR fill). Esc closes
- **Option loss model**: Black-Scholes move applied to the market mid — `premium@stop = max(0, mid + BS(stop,T) − BS(spot,T))` so IV-skew level offsets cancel; falls back to Δ+½Γ·move² when the contract has no IV (model flag 'bs'/'approx'). Clamped so a loss-direction move can't show a gain. loss/ct = (mid − premium@stop) × 100, contracts = floor(risk$ / loss per ct). Calls priced off the long stop, puts off the short stop. Mid cells flag wide spreads (>10% of mid) in amber
- **Overnight line**: every loss@stop also computes premium@stop at T − 1 day (atStopON/atLodON). Detail rows and cards show a quiet 'held overnight: −$X (−Y%)' line when it's worse than today's — no controls; 0DTE naturally shows full loss to intrinsic
- **Expected move**: ATM straddle mid for the loaded expiry, shown in the filter row (emInfo), computed pre-zone-filter
- **IV percentile**: ivInfo in the filter row shows the loaded expiry's ATM IV ranked against the past year's rolling HV20 distribution (hvDist, from the 380-day history fetch). Amber ≥80th (rich), green ≤20th (cheap). True IV Rank isn't available from Tradier (no historical IV endpoint); an own-IV diary was tried and removed by request
- **HV20 + prior day**: fetchAdr's daily history also yields hv20 (annualized 20d stdev of log returns) and prevDay {h,l,c}. Detail rows show IV vs HV20 (amber >1.5×). Chart draws PDH/PDL/PDC gray dashed lines when inside the visible range
- **Recent tickers**: last 5 symbols as chips under the symbol row (recent_tickers, MRU, current excluded). Chain auto-scrolls to the ATM row on user-driven loads only (pendingAtmScroll — never on live polls). Live mode is a duration ladder: tap ⚡ for 1m @ 5s ticks, tap again to extend 5m @ 10s, again 30m @ 20s, again stops (LIVE_MODES). Refreshes pinned (and, in Positions view, saved) cards every 4th tick offset from the chart. Backgrounding PAUSES the session (remaining time kept) and returning resumes it
- **Reverse sizing**: Shares stat and Contracts stats (detail row, pinned cards) are editable inputs; committing a quantity writes risk$ back (riskForQty) and everything re-renders from it. Quantity floors use unitsFor (epsilon-tolerant) so counts round-trip exactly
- **Zone filter deltas**: filtering uses a BS-computed delta (filterDelta — Tradier greeks can print flat 1.000 across all ITM strikes, defeating any threshold); the Δ column still displays the API value
- **Zone filter**: radio segmented control (zoneMode: otm | itm | both | all → derives zoneFilter) — OTM (|Δ| ≥ .20 floor), ITM→ATM (a DEPTH LIMIT: |Δ| ≤ setting, default .80, band runs from the ATM strike down to it; ATM strike always shows with a blue ATM badge; deeper = All view), Both (union → contiguous band around ATM), All (no filter). One mode at a time; each Δ floor input only visible when its zone is active. Keys 1/2/3/4. ATM strike computed from the full chain pre-filter. Zones apply ONLY to single-side views. The Both-sides T-chart ignores them entirely and instead shows a configurable window of ± N strikes around ATM (bothStrikes input, default 8, persisted as both_strikes; zone seg + floors hidden there via updateChainControls). Any zone pick (chip or keys 1–4) from Both view switches to Calls first; the chosen zone mode is remembered across side switches
- **Entry price**: optional underlying entry input (blank = current price) in the Entry & stops row, amber border/line (blue collided with VWAP). Shares size off |entry − stop|; chain prices premium@entry via the same BS move and losses run entry→stop (entryPrem is the cost basis for cts/total/loss%). Drawn on both charts, cleared on symbol change; sim uses entryPrem
- **Loss/ct cells** show dollar loss with % of premium lost stacked below, color coded (green <25%, amber 25–60%, red >60%)
- **Vol/OI**: bold columns with blue tint, resting in muted gold (--gold #d9b968); BOTH turn full amber together when vol > OI (the signal is about the pair — they're always read together). This emphasis is intentional — don't tone it down
- **Expirations**: tabs with a DTE line under each date, monthlies (third Friday, or Thursday-before if holiday) badged amber with "M" corner tag. Shows 12 + "+N more" expand
- **Quick lookup**: order-free shorthand parser — tokens classified by shape (ticker / strike / date / call-put), any order, `/` or `.` date separators ("AAPL 245 6/20", "9.18 300 aapl", "SPY 580 put 6/18/26") → OCC symbol → pinned result cards, newest on top. Dotted number = date unless a date is already set (then strike); bare c/p = type only when another word can be the ticker. Spread shorthand: a slashed strike pair (105/115 — anything slashed that can't be a date) or two bare numbers plus cds/pds ('rbrk 105/115 8/28 cds') → spread pinned card; cds buys the lower strike, pds the higher (debit normalization), both legs fetched in one quotes call, credit combinations rejected. A pair without cds/pds parses as '?'
- **Debit spreads** (two-leg verticals, the only multi-leg supported): '+ debit spread' in a single-side detail row marks the long leg (detailReg by OCC symbol), a banner asks for the short strike, tapping a row completes it (direction/credit validated; Esc or side/mode/chain changes cancel via cancelSpread). Spread cards are pinnedData entries with kind:'spread' + legs[{K,iv,side,occ,mid,delta}]; d.mid = net debit, d.delta/gamma = net. cardValueAt(d,S,T) nets the legs' BS values and recalcPinnedStop/sim/saved math all run through it, so stop-value, overnight, P&L, and the simulator (legs-aware simCurve — max-loss floor = full debit naturally) just work. SIZED BY FULL DEBIT (sizeUnit(d)), not loss@stop: defined risk. Card shows max profit (width − debit), breakeven (K1 ± debit), reward/risk; refreshCardData requotes both legs in one call. Share/copy label as '100/110c debit spread'
- **Tools**: the header wordmark IS the top-level nav — 'Size / Tools', click Size = calculator, click Tools = tools view (setView 'utils', key u; active side bright, other dimmed). Tools view hides ALL calculator surfaces including the API and Account & Risk cards. Currently holds the % gain card (bought at / current price → gain %, per-unit change, multiple; renderGain, no API) — add future small tools here
- **Saved positions**: their own tab on the big switcher (Shares / Options / Positions, count badge, key v). positionsView is a display state, NOT a mode — currentMode stays shares/options underneath (tradeCtx etc. unaffected); selecting it hides all sizing surfaces and shows only saved cards, auto-refreshing quotes on open when a key exists. 'save' on a pinned card promotes it to a persisted position (localStorage, savedData). Editable entry price (defaults to mid) and contracts held — these do NOT write back to risk$ (tracking, not sizing). Shows P&L now vs entry, loss @ stop measured from entry (flips to green 'Locked @ stop' when premium@stop > entry), % of acct. Per-card and refresh-all requote via refreshCardData (shared with pinned) Each card's stop is editable in its header (recalcPinnedStop rederives premium@stop, loss/ct, loss %, contracts). Cards show an as-of time and a per-card ↻ refresh (default LOD/HOD stops track fresh levels, user-set stops stay); "refresh all" bar appears at 2+ cards
- **Daily chart**: second canvas pane LEFT of the 5-min when side-by-side; when STACKED (<700px and the ≥1100 chart column) the 5-min working chart leads and daily sits below (#chartCol5 order:-1), ~90 sessions from the ADR history fetch (incl. today's forming bar), candles + daily 8 EMA + the context's stop lines. Click sets a stop (setStopFromPrice, shared with 5-min); hover = full crosshair (vertical bar line + horizontal price line with axis tag, like the 5-min and sim charts) and shares the OHLC readout with a '1D' prefix. Chart card shows whichever panes have data (updateChartVisibility) — daily works without a brokerage-linked key even when timesales doesn't
- **Intraday chart**: canvas candlesticks (hand-rolled, no chart lib) directly under the quote bar. Interval chips 5m/15m/30m/65m (chartInterval, persisted): 5m native from timesales, larger intervals aggregated client-side from 5m (buckets never cross a session), with more lookback per interval (CHART_SESSIONS 1/2/3/5). VWAP resets per session; HOD/LOD dashed lines come from the LAST session only; faint separators at session boundaries. Walks back up to 6 sessions if today has no data. Dashed lines: HOD/LOD, red long stop, green short stop. Overlays: blue VWAP, purple 8 EMA. Click/tap = set stop (side-aware). Touch: LONG-PRESS (~220ms hold) engages the crosshair via attachTouchCrosshair — the chart owns the gesture (preventDefault, page holds still), and RELEASING SETS THE STOP at the final crosshair price (onEnd gets the last point; the trailing click is suppressed so it can't double-fire; sim chart release is read-only). Quick swipes scroll the page normally, plain taps still set stops. Mouse hover = full crosshair (vertical bar line + horizontal price line with axis tag) + OHLC readout. Chart header shows ADR14 (from `/markets/history` daily bars, today excluded) as $ and % of price, plus % of the ADR consumed from the trade's reference level — LOD when long, HOD when short (shares follow the direction toggle, options follow chain side, Both shows both); amber at ≥90% consumed
- **Keyboard shortcuts**: single keydown listener, ? shows the map. Keys ignored while typing in fields
- **Live mode**: ⚡ button polls quote + current chain each tick, chart every 4th tick, with countdown and overlap guards (duration ladder — see Recent tickers bullet)

- **Extended hours**: extSession(q) picks the fresher of two signals inside the PRE (4:00–9:30 ET, vs prevclose) / AH (≥16:00, vs close) windows — the last trade print, or the extended NBBO mid (bid/ask with their own timestamps; Tradier often freezes `last` at the 15:59 closing print). Spreads >5% of mid rejected as overnight junk; null during RTH or when nothing is from today (ET). Shown as a dim secondary figure in the quote bar (qExt) and sticky bar
- **Sizing anchors on effectivePrice(q)** — the extended price when live, else last: entryVal blank default, renderShares/renderChain/shareShares, ADR usage, chart-click both-view split, sim spot, quick lookup + card refresh underlying. The entry input's placeholder cues it ("AH 181.00"). The headline qPrice and sticky-bar price stay the official last with the ext figure alongside

## Conventions
- Dark trading-terminal theme, CSS variables in `:root`, monospace tabular numerals for all figures
- Two-pane desktop (≥1100px, ALL modes, media-only — no toggle): .app is a grid (controls/tables in the left column, header full-width). #quoteSection is display:contents so its children join the app grid; #chartWrap takes the right column, grid-row 2/span 60, normal flow (it was sticky briefly — that made the charts shift against the page while scrolling; don't re-add). Charts sit beside the ticker card from load. The left column is chain-pane width, so isMobileChain() is true at ≥1100 too (compact columns/formats) — except Δ and OI (.m-delta/.m-oi re-shown, OI in k-format via fmtKM, cell padding 3px there; twoPaneChain() = matchMedia(1100), colspans both 13 / single 8 / banner 6). quoteSection visibility uses style.display '' (never 'block') so display:contents can engage
- Saved cards carry a blue inset left accent (.saved-card) to scan pinned vs positions
- Keyboard help card is grouped (navigate / views / chain / data)
- Mobile rows (≤600px): preset chip rows (#riskPresets, #riskUsdRow) are single-line EQUAL-SPLIT (chips flex 1 1 0, labels hidden — % and $ speak for themselves; nowrap !important since inline styles carry flex-wrap:wrap); #recentTickers stays side-swipe (unbounded list). Editing $ presets is in-place: ✎ turns each chip into a number box (blank = delete, trailing '+' box = add) and itself into ✓ to save (editingUsd state, Enter also saves); mobile quick-lookup parse preview sits on its own line under the input (the absolute in-field overlay overlapped the typed text at phone widths); ticker row is one line (#symbolField flexes, .field min-width 0, .btn-word spans hide → 'Load'/'↻'); Entry & stops = Direction full-width, then entry+stop as equal halves, hint on its own line
- Daily chart toggle: 'D1' chip in the interval row AND the tappable daily caption ('tap to hide') both call toggleDaily (show_daily persisted); updateChartVisibility gates chartColD on showDaily, syncs the D1 active state, and repaints on re-show
- Card headers (pinned/saved/spread): desktop = one line, flex-wrap nowrap so the .pinned-meta shrinks/ellipsizes instead of splitting the .card-act cluster; mobile (<600px) = identity line, full-width meta, right-aligned action row (flex order), badges hidden
- The chart card is a DIRECT app child right after the ticker card (not inside quoteSection) — on mobile the charts sit immediately under Entry & stops for tap-to-set-stop; updateChartVisibility also gates on positionsView since the card no longer inherits quoteSection's hiding
- Page order = trade order: setup cards (API collapsible chip, Account & Risk), ticker + stops, quick lookup (collapsible, q expands), pinned cards, quote bar, chart, then the chain. Chart sits ABOVE the chain — levels before contracts
- Sticky context bar (fixed, appears when scrolled past the quote card): symbol, price/chg, LOD/HOD, ADR used %, risk $, chart/chain jump chips (jumpTo — smooth-scroll, offset by bar height), and a live chip (sbLive — start/extend/stop live from anywhere on the page, synced with the main button via syncSbLive; stopPropagation so it doesn't trigger the bar's back-to-top). Click elsewhere on the bar = back to top
- Stop inputs carry their chart line colors (red long stop, green short stop — a stop is a loss point, and it groups with the level it defaults to: LOD red, HOD green). Recalc-triggered re-renders pulse stat values (.pulse). Errors are fixed-position toasts, self-dismiss in 6s
- Big Shares/Options segmented switcher at top of ticker card — keep it prominent
- localStorage wrapped in try/catch (`store` helper) so sandboxed previews don't crash
- PWA: manifest.json + icon-180/512.png + sw.js (network-first, same-origin GETs only — API calls pass through; cached fallback offline). Registered only on https. Fixes iOS home-screen staleness — fresh version on every online open
- Durability: navigator.storage.persist() requested at init. Export/Import backup buttons in the API card (BACKUP_KEYS → JSON file + clipboard; import merges saved_positions rather than clobbering — deleted_positions tombstones keep deletes deleted — overwrites the rest, reloads). Backup file contains the API key — hints tell the user to keep it private. Green toast variant: .error.ok via showToast()
- iOS home-screen meta tags present (apple-mobile-web-app-*) — file is meant to be hosted (GitHub Pages) and added to iPhone home screen
- Wheel over a focused number input blurs it so the page scrolls instead of spinning the value
- Owner's style: direct, terse. No em dashes in user-facing copy.

## Known caveats / next ideas
- Loss model includes gamma but still ignores theta/IV shift — noted in detail rows, fine for intraday sizing
- Last ticker persists in localStorage and auto-loads on open when a key is saved
- `timesales` needs a Tradier brokerage-linked production key; chart hides quietly if unavailable
- If hosted-page CORS to api.tradier.com ever fails, fix is a small Cloudflare Worker proxy
- Possible future: stop-on-premium mode (vs stop-on-underlying), condensed mobile column set for <500px, OI static intraday (OCC settles overnight)
