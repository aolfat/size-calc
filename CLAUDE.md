# Size Calculator (index.html)

Single-file trade position sizing tool. No build step, no dependencies, no framework — one self-contained HTML file with vanilla JS. Keep it that way.

## What it does
Sizes shares and options positions off a dollar risk amount (account size × risk %), using Tradier's REST API directly from the browser (key stored in localStorage, never in the file). Account size and risk % persist in localStorage. Risk $ is styled as the loud number (big, bold, red — it's the max loss). Risk % preset chips: .25/.50/1/2/3%, active chip tracks whatever the current % resolves to.

## Architecture
- **Tradier API**: `api.tradier.com/v1` (or sandbox), Bearer auth. Endpoints used: `/markets/quotes` (greeks=true), `/markets/options/expirations`, `/markets/options/chains`, `/markets/timesales` (5min interval, for the chart)
- **Stops**: ONE global stop pair in the ticker card, used everywhere. Long stop (shares-long + calls, blank = LOD) and short stop (shares-short + puts, blank = HOD). Only the stop matching tradeCtx() is shown/drawn (shares follow the Long/Short toggle, options follow chain side; Both view shows both). Chart click sets the context's stop; in Both view, below price = long, above = short. Quick lookup uses the pair when its ticker matches the loaded quote, else that underlying's LOD/HOD. Inputs clear on symbol change
- **Shares mode** (default): Shares = risk$ / |entry − stop|. The Long/Short toggle lives FIRST in the Entry & stops row (direction is the first decision; dirField hidden in options mode where chain side plays that role)
- **Options mode**: straddle T-chart — calls left, strike center column, puts right, mirrored columns (Cts, Loss/ct, OI, Vol, Δ, Mid | Strike | reversed). Single-side views (Calls/Puts) use a wider layout with bid/ask/IV/@stop/total. Mobile (<500px) hides OI/Δ/bid/ask/IV/@stop and compacts number formats. Chain header is locked while scrolling: sticky thead — on desktop the chain is its own scroll panel (.chain-scroll, max-height ~100vh); on mobile (table fits, no scroll wrapper) it sticks to the page below the context bar (--sbh offset)
- **Simulate returns**: Black-Scholes (normCdf via Abramowitz-Stegun, RISK_FREE 4%) canvas modal — return % over time (now → expiry) at a slider-chosen underlying price, IV held constant. Green above breakeven / red below via canvas clipping, max-loss floor, drag crosshair readout (est $/ct, %, $ P&L × qty). Price chips: stop / now / 1R / 2R (R = distance to stop, side-aware). Entry points: chain detail row (simReg by OCC symbol), pinned cards (entry = mid), saved cards (entry = YOUR fill). Esc closes
- **Option loss model**: Black-Scholes move applied to the market mid — `premium@stop = max(0, mid + BS(stop,T) − BS(spot,T))` so IV-skew level offsets cancel; falls back to Δ+½Γ·move² when the contract has no IV (model flag 'bs'/'approx'). Clamped so a loss-direction move can't show a gain. loss/ct = (mid − premium@stop) × 100, contracts = floor(risk$ / loss per ct). Calls priced off the long stop, puts off the short stop. Mid cells flag wide spreads (>10% of mid) in amber
- **Overnight line**: every loss@stop also computes premium@stop at T − 1 day (atStopON/atLodON). Detail rows and cards show a quiet 'held overnight: −$X (−Y%)' line when it's worse than today's — no controls; 0DTE naturally shows full loss to intrinsic
- **Expected move**: ATM straddle mid for the loaded expiry, shown in the filter row (emInfo), computed pre-zone-filter
- **HV20 + prior day**: fetchAdr's daily history also yields hv20 (annualized 20d stdev of log returns) and prevDay {h,l,c}. Detail rows show IV vs HV20 (amber >1.5×). Chart draws PDH/PDL/PDC gray dashed lines when inside the visible range
- **Recent tickers**: last 5 symbols as chips under the symbol row (recent_tickers, MRU, current excluded). Chain auto-scrolls to the ATM row on user-driven loads only (pendingAtmScroll — never on live polls). Live mode refreshes pinned (and, in Positions view, saved) cards every 4th tick offset from the chart, and stops when the app is backgrounded
- **Reverse sizing**: Shares stat and Contracts stats (detail row, pinned cards) are editable inputs; committing a quantity writes risk$ back (riskForQty) and everything re-renders from it. Quantity floors use unitsFor (epsilon-tolerant) so counts round-trip exactly
- **Zone filter**: radio segmented control (zoneMode: otm | itm | both | all → derives zoneFilter) — OTM (≥.20 floor), ITM→ATM (≥.65 floor, ATM strike always shows), Both (union), All (no filter). One mode at a time; each Δ floor input only visible when its zone is active. Keys 1/2/3/4. ATM strike computed from the full chain pre-filter. ITM/Both are DIRECTIONAL: picking them from the Both-sides T-chart auto-switches to Calls view with a toast (per-side ITM in the mirrored chart = strike extremes = reads as the full chain); returning to Both downgrades the zone to All. OTM stays allowed in the T-chart — the mirrored OTM band around ATM is the app's native default view
- **Entry price**: optional underlying entry input (blank = current price) in the Entry & stops row, blue border/line. Shares size off |entry − stop|; chain prices premium@entry via the same BS move and losses run entry→stop (entryPrem is the cost basis for cts/total/loss%). Drawn on both charts, cleared on symbol change; sim uses entryPrem
- **Loss/ct cells** show dollar loss with % of premium lost stacked below, color coded (green <25%, amber 25–60%, red >60%)
- **Vol/OI**: bold bright columns with blue tint; Vol turns amber when vol > OI (new positioning signal). This emphasis is intentional — don't tone it down
- **Expirations**: tabs, monthlies (third Friday, or Thursday-before if holiday) badged amber with "M" corner tag. Shows 12 + "+N more" expand
- **Quick lookup**: order-free shorthand parser — tokens classified by shape (ticker / strike / date / call-put), any order, `/` or `.` date separators ("AAPL 245 6/20", "9.18 300 aapl", "SPY 580 put 6/18/26") → OCC symbol → pinned result cards, newest on top. Dotted number = date unless a date is already set (then strike); bare c/p = type only when another word can be the ticker.
- **Saved positions**: their own tab on the big switcher (Shares / Options / Positions, count badge, key v). positionsView is a display state, NOT a mode — currentMode stays shares/options underneath (tradeCtx etc. unaffected); selecting it hides all sizing surfaces and shows only saved cards, auto-refreshing quotes on open when a key exists. 'save' on a pinned card promotes it to a persisted position (localStorage, savedData). Editable entry price (defaults to mid) and contracts held — these do NOT write back to risk$ (tracking, not sizing). Shows P&L now vs entry, loss @ stop measured from entry (flips to green 'Locked @ stop' when premium@stop > entry), % of acct. Per-card and refresh-all requote via refreshCardData (shared with pinned) Each card's stop is editable in its header (recalcPinnedStop rederives premium@stop, loss/ct, loss %, contracts). Cards show an as-of time and a per-card ↻ refresh (default LOD/HOD stops track fresh levels, user-set stops stay); "refresh all" bar appears at 2+ cards
- **Daily chart**: second canvas pane LEFT of the 5-min (stacked above it <700px), ~90 sessions from the ADR history fetch (incl. today's forming bar), candles + daily 8 EMA + the context's stop lines. Click sets a stop (setStopFromPrice, shared with 5-min); hover shares the OHLC readout with a '1D' prefix. Chart card shows whichever panes have data (updateChartVisibility) — daily works without a brokerage-linked key even when timesales doesn't
- **5-min chart**: canvas candlesticks (hand-rolled, no chart lib) directly under the quote bar. Walks back up to 6 sessions if today has no data. Dashed lines: HOD/LOD, red long stop, green short stop. Overlays: blue VWAP, purple 8 EMA. Click = set stop (side-aware). Hover/touch-drag = full crosshair (vertical bar line + horizontal price line with axis tag) + OHLC readout. Chart header shows ADR14 (from `/markets/history` daily bars, today excluded) as $ and % of price, plus % of the ADR consumed from the trade's reference level — LOD when long, HOD when short (shares follow the direction toggle, options follow chain side, Both shows both); amber at ≥90% consumed
- **Keyboard shortcuts**: single keydown listener, ? shows the map. Keys ignored while typing in fields
- **Live mode**: ⚡ button polls quote + current chain every 5s for 60s, chart every ~20s, with countdown and overlap guards

## Conventions
- Dark trading-terminal theme, CSS variables in `:root`, monospace tabular numerals for all figures
- Page order = trade order: setup cards (API collapsible chip, Account & Risk), ticker + stops, quick lookup (collapsible, q expands), pinned cards, quote bar, chart, then the chain. Chart sits ABOVE the chain — levels before contracts
- Sticky context bar (fixed, appears when scrolled past the quote card): symbol, price/chg, LOD/HOD, ADR used %, risk $. Click = back to top
- Stop inputs carry their chart line colors (red long stop, green short stop — a stop is a loss point, and it groups with the level it defaults to: LOD red, HOD green). Recalc-triggered re-renders pulse stat values (.pulse). Errors are fixed-position toasts, self-dismiss in 6s
- Big Shares/Options segmented switcher at top of ticker card — keep it prominent
- localStorage wrapped in try/catch (`store` helper) so sandboxed previews don't crash
- PWA: manifest.json + icon-180/512.png + sw.js (network-first, same-origin GETs only — API calls pass through; cached fallback offline). Registered only on https. Fixes iOS home-screen staleness — fresh version on every online open
- Durability: navigator.storage.persist() requested at init. Export/Import backup buttons in the API card (BACKUP_KEYS → JSON file + clipboard; import merges saved_positions rather than clobbering, overwrites the rest, reloads). Backup file contains the API key — hints tell the user to keep it private. Green toast variant: .error.ok via showToast()
- iOS home-screen meta tags present (apple-mobile-web-app-*) — file is meant to be hosted (GitHub Pages) and added to iPhone home screen
- Wheel over a focused number input blurs it so the page scrolls instead of spinning the value
- Owner's style: direct, terse. No em dashes in user-facing copy.

## Known caveats / next ideas
- Loss model includes gamma but still ignores theta/IV shift — noted in detail rows, fine for intraday sizing
- Last ticker persists in localStorage and auto-loads on open when a key is saved
- `timesales` needs a Tradier brokerage-linked production key; chart hides quietly if unavailable
- If hosted-page CORS to api.tradier.com ever fails, fix is a small Cloudflare Worker proxy
- Possible future: stop-on-premium mode (vs stop-on-underlying), condensed mobile column set for <500px, OI static intraday (OCC settles overnight)
